# Geospatial Codebase
Developed at IITTNIF, this repository contains geospatial tools and analytical scripts supporting spatial data processing, mapping, and geographic intelligence workflows.

## Purpose
To provide a unified, reproducible codebase for geospatial analysis tasks undertaken at IITTNIF — including terrain analysis, spatial data integration, coordinate transformation, and map generation.

## Core Capabilities
- Spatial data ingestion (raster and vector formats)
- Coordinate reference system (CRS) conversion and reprojection
- Geospatial querying and feature extraction
- Map visualization and export
- Integration with GIS platforms and satellite data sources

## Requirements
- Python 3.14
- GDAL 
- GeoPandas
- Shapely
- Rasterio
- Folium & Matplotlib (for visualization)

Install dependencies:
```bash
pip install -r requirements.txt
```
